# Source index

- Engine/Core: clock, event bus, service registry, scheduler, logging and validation.
- Engine/Scene: scene graph, entities, transforms, components, cameras, lights, mesh/material settings, serialization and validation.
- Engine/Rendering: mesh data, primitive geometry, camera math, orbit controls, picking rays, grid generation, render queues and resource descriptors.
- Engine/Physics: bodies, colliders, materials, world integration and hit records.
- Engine/Scripting: safe command parser/VM, script assets, diagnostics, context and scheduler.
- Engine/Assets: asset records/database, extension classification, dependency graph and search index.
- Engine/Editor: inspector metadata, selection, tools, undo, console, layout, theme and preferences.
- Engine/Build: Android build profiles, validation and pipeline contracts.
- Engine/Input, Audio, Animation: device input and content foundations.
- Native: C++17 JNI sample source and integration notes.
